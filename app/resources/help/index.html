JDP Presenter Help

Setup, library management, schedule building, presenting, and recording

1. Settings

  1. Open File → Settings.
  2. Under Libraries, choose locations for Bibles, songs, services, media, and recordings.
  3. Under Audio, choose input and monitoring devices. Use Recording for format, quality, output folder, and prompt behavior.
  4. Under Keyboard Shortcuts, click any shortcut button and press its replacement key combination. Conflicting shortcuts are rejected; Restore Defaults returns to the standard layout.
  5. Under General, choose whether JDP Presenter checks GitHub Releases for new versions at startup. A manual check is always available from Help → Check for Updates.
  6. Save changes. Restart JDP Presenter after changing a library location.

2. Import Resources

  1. Choose File → Import.
  2. Select the resource format: Quelea song pack (.qsp), OpenLyrics archive (.zip), individual song XML/script, Bible, or library package.
  3. Choose Replace only when the active library should be cleared first.
  4. Select the source file and wait for the imported/failed summary.
  5. For media, open Add Media and choose Import to Library, or drag supported image, video, and audio files directly onto the schedule.

Replace affects the selected library type. Existing application settings are retained.

3. Add Items to the Schedule

  1. Select the item after which new content should be inserted.
  2. Use the Song, Scripture, Text, or Media toolbar icon, or type into Quick Add.
  3. Quick Add accepts song/media names and references such as Joh 1 or John 1:1-14 (CSB). Without a version, the last-used Bible is selected.
  4. Press Enter to insert the first result. Use Up/Down inside the results when another match is needed.
  5. Use the toolbar arrow buttons or drag schedule rows to reorder them.
  6. Right-click a scheduled song and choose Edit Song to update the library song and its scheduled slides.

4. Run the Schedule on Desktop

  1. Choose Output → View Output on Secondary Screen, or use the monitor button on the Output toolbar.
  2. Select a schedule item. Double-click it to make it live.
  3. Use the configured item and slide shortcuts to navigate. The current assignments are listed below and can be changed in Settings → Keyboard Shortcuts.
  4. Use Show/Hide to switch projection visibility and Black Output to blank it immediately.
  5. For audio/video items, use Play/Pause and the seek control. Global shortcuts are suspended while typing in Quick Add.
  6. Scripture poetry preserves source line breaks and keeps a verse together on one page when it fits. Stanza gaps appear only when the imported Bible contains explicit blank lines.

5. Run from the Mobile Remote

  1. Connect the phone/tablet to the same network as the presenter computer.
  2. Show the QR code from the Output menu and scan it.
  3. The remote shows current title, page number, previous/next, Live/Black, media, and recording controls.
  4. On portrait phones, current and next previews appear below the controls. On tablets and desktop browsers (768 px or wider), they appear above the controls in a two-column layout.

6. Start, Pause, and Stop Recording

Desktop

  1. Click the Record icon or use the configured Start/Stop Recording shortcut.
  2. Confirm the schedule-based filename, format, and quality. Select Remember Settings to skip this prompt next time.
  3. Use the recording indicator or configured Pause/Resume Recording shortcut. Re-enable prompting under Settings → Recording.
  4. Stop recording to finalize the file. WAV works without additional software; MP3 and M4A conversion require a separately installed FFmpeg executable on PATH.

Mobile remote

  1. Tap Start. The current service name and saved recording settings are used.
  2. Tap Pause; tap Resume to continue.
  3. Tap Stop to finalize the file.
