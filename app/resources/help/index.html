1. Getting Started

JDP Presenter opens two windows: the Control window where you build and run the schedule, and the Output window that is projected to the congregation.

  1. Two monitors: when a second display is connected at launch, the Output window opens full-screen on it automatically and the Control window stays on the primary display.
  2. One monitor: the Output window opens as a normal window behind the Control window so it never covers your controls. Use Output → View Output on Secondary Screen (or the monitor button on the toolbar) to send it full-screen once a projector is connected.
  3. Press ? (default) at any time to see the current keyboard shortcuts.

2. Toolbar Buttons

Hover any button for its tooltip. The Control window has five toolbars: the Main toolbar across the top, the Schedule toolbar above the schedule list, and the Output, Media, and Media Scale toolbars above the preview.

3. Settings

  1. Open File → Settings…. Select a page on the left and edit its values on the right.
  2. General — auto-save the service on changes, confirm before deleting items, remember window positions and sizes, and check for new versions on startup.
  3. Presentation — default aspect ratio (4:3, 16:9, 16:10), default font scale (50–300%), default media scale (Fit, Original, Fill Width, Fill Height), and whether to auto-advance to the next item after the last slide.
  4. Audio — recording input and monitoring output devices (or System Default).
  5. Recording — default format (MP3, WAV, AAC (M4A)), quality, output folder, and whether to always prompt when starting a recording.
  6. Keyboard Shortcuts — click any shortcut button and press its replacement key combination. Conflicting shortcuts are rejected; Restore Defaults returns to the standard layout.
  7. Libraries — folders for Bibles, songs, services, and media. Location changes take effect after JDP Presenter restarts.
  8. Remote Control — the remote server port (default 5183) and whether to auto-show the pairing QR code when the server starts.
  9. Integrations — optional OpenAI API key. Dropbox sync is not yet implemented.

4. Import, Back Up, and Restore Libraries

  1. Choose File → Import… or the Import toolbar button.
  2. Select the resource type: JDP Library package (.jdplibrary, songs and Bibles together), Bible — Zefania XML, or songs from a Quelea song pack (.qsp), Quelea .script, OpenLP database (.sqlite), OpenLyrics library (.zip), OpenLyrics XML (single file), or an OpenSong XML folder.
  3. Tick Replace existing library contents when importing only when the matching library should be cleared first.
  4. Click Choose & Import…, select the source, and wait for the imported/failed summary.
  5. Backup Libraries… saves all songs and Bibles to a portable .jdplibrary file; Restore Libraries… replaces the libraries from a .jdplibrary (or legacy song-backup .zip).
  6. For media, open Insert → Add Media… and use Import to Library (Files… or Folder…), or drag supported image, video, and audio files directly onto the schedule.

Replace affects only the selected library type. Application settings are always retained.

5. Services

  1. File → New starts an empty service; Open… loads a saved service file; Save / Save As… write it to the services folder.
  2. With Auto-save service on changes enabled in Settings, edits are written automatically; otherwise you are prompted to save unsaved changes when closing.
  3. The last opened service is reopened at the next launch.

6. Build the Schedule

  1. Select the item after which new content should be inserted.
  2. Use Insert → Add Song…, Add Scripture…, Add Text…, or Add Media… (also on the schedule toolbar), or type into Quick Add.
  3. Quick Add searches song titles and authors (punctuation such as apostrophes and commas is ignored), media file names, and Scripture references such as Joh 1 or John 1:1-14 (CSB). Without a version, the last-used Bible is selected.
  4. Press Enter to insert the first result, or use Up/Down to pick another match. Up to 30 results are listed.
  5. Add Song… opens the Song Library (see Songs below): search, preview, set the play order, then Add to Service.
  6. Add Scripture… lets you choose a translation, type a reference such as 1 Cor 13:4-7, preview the verses, and insert.
  7. Add Media… opens the Media Library (Images, Videos, Audio) with preview, per-item scale mode, Add from Disk… for one-off files, and Delete from Library….
  8. Use the Move Up / Move Down toolbar buttons or drag rows to reorder; Delete Selected Item removes an item.
  9. Right-click a scheduled song and choose Edit Song… to update the library song and refresh its scheduled slides.

7. Songs and the Song Library

Open the Song Library with Insert → Add Song… or the Add Song… button on the Schedule toolbar. Type in Search title or author… to filter; select a song to preview all its verses in order.

Add a new song to the library

  1. In the Song Library, click New Song. The New Song editor opens.
  2. Enter the Title (a blank title is saved as “Untitled”) and, optionally, Author, CCLI number, Copyright, Key, Tempo, and Capo.
  3. Paste or type the lyrics into the large box. Separate each section with a blank line. Put an optional heading on the first line of a section — Verse 1, Verse 2, Chorus, Bridge, Pre-Chorus, or Tag. Sections without a heading are numbered as verses automatically.
  4. Set the Play Order using the short section labels, for example v1 c v2 c b c (v = verse, c = chorus, b = bridge, p = pre-chorus, tag = tag). Leave it blank to present the sections in the order they were typed.
  5. Click OK. The song is saved to the song library and appears in the list immediately; it is also found by Quick Add.
  6. To use it now, select it and click Add to Service. Changing the Verse order box in the library before adding affects only that scheduled copy, not the saved song.

Example lyrics layout:
Verse 1
Crown Him with many crowns,
The Lamb upon His throne;
(blank line)
Chorus
Awake, my soul, and sing…

Edit or remove a song

  1. Select the song and click Edit Song…, or right-click a song already on the schedule and choose Edit Song…; saving refreshes the library song and any scheduled slides.
  2. Delete… removes the selected song from the library after confirmation. Songs already on a schedule keep their slides.

To bring in many songs at once, use File → Import… (Quelea, OpenLP, OpenLyrics, OpenSong, or a .jdplibrary package) — see Import.

8. Themes

  1. Theme → Theme Gallery… lists prebuilt looks; select one and apply it to the current service.
  2. Theme → Theme Editor… adjusts the background colour, Scripture verse text colour and size, reference colour, whether the Bible version label is shown, song lyric colour and size, and whether song metadata is shown.
  3. Use Output → Font Size → Increase / Decrease (toolbar A− / A+) for quick live adjustments without changing the theme.

9. Present

  1. Connect the projector. If it was connected before launch the Output window is already full-screen on it; otherwise choose Output → View Output on Secondary Screen or the monitor toolbar button.
  2. Set the canvas with Output → Aspect Ratio (4:3, 16:9, 16:10) to match the projector.
  3. Select a schedule item. Double-click it to make it live. The Next Item preview shows what follows.
  4. Navigate with the configured item and slide shortcuts (listed below; change them in Settings → Keyboard Shortcuts).
  5. Show / Hide (Output menu and toolbar) toggles projection visibility; the Black Output shortcut blanks the screen instantly without changing position.
  6. For audio/video items use Play/Pause Media, the seek slider, and the media scale buttons (Fit, Original, Fill Width, Fill Height). Global shortcuts are suspended while typing in Quick Add.
  7. Scripture poetry preserves source line breaks and keeps a verse together on one page when it fits. Stanza gaps appear only when the imported Bible contains explicit blank lines.

10. Run from the Mobile Remote

  1. Connect the phone/tablet to the same network as the presenter computer.
  2. Choose Output → Show QR Code (or the QR toolbar button) and scan it; the pairing dialog also shows the URL to type manually. The port can be changed under Settings → Remote Control.
  3. The remote shows the current title and page number, ◀ Prev / Next ▶, Live and Black toggles, media Play / Pause / Stop, recording Start / Pause / Stop, and a Connected/Disconnected indicator.
  4. On portrait phones, Current and Next previews appear below the controls. On tablets and desktop browsers (768 px or wider), they appear above the controls in a two-column layout.

11. Record the Service

Desktop

  1. Click the Record toolbar button or use the configured Start/Stop Recording shortcut.
  2. Confirm the schedule-based filename, format, and quality. Select Remember Settings to skip this prompt next time; re-enable it under Settings → Recording.
  3. Use the recording indicator or the configured Pause/Resume Recording shortcut while recording.
  4. Click Stop to finalize the file. WAV works without additional software; MP3 and M4A conversion require a separately installed FFmpeg executable on PATH.

Recordings pane

  1. The Recordings pane in the Control window lists saved recordings newest first with their time and size.
  2. Use the pane buttons to refresh the list, open the recordings folder, play the selected recording, or stop playback; double-click a recording to play it.
  3. Right-click a recording for Play, Delete, or Show In Explorer (Finder/file manager on other systems).

Mobile remote

  1. Tap Start. The current service name and saved recording settings are used.
  2. Tap Pause; tap Resume to continue.
  3. Tap Stop to finalize the file.

12. Export and Print

  1. File → Export… offers a Summary (plain-text outline with item numbers, titles, and song verse counts) or the Full Service (Markdown containing Scripture, lyrics, text, and media references). Use Copy to Clipboard or Save As… (.txt / .md).
  2. File → Print… opens the same Summary or Full Service content as a preview you can copy or save for printing.

13. Updates

  1. JDP Presenter checks GitHub Releases at startup when Check for new versions on startup is enabled; Help → Check for Updates… runs a check at any time.
  2. When a newer version exists, choose Download & Install. The update is downloaded with a progress indicator.
  3. Windows: JDP Presenter saves your work, closes, and the installer upgrades it in place and relaunches the app. Windows may ask for permission to continue.
  4. macOS: the downloaded disk image opens; drag JDP Presenter into Applications to replace the current version. Linux: the folder containing the downloaded archive opens; extract it over the existing installation.
  5. Open Release Page opens the release notes and downloads in a browser instead.
